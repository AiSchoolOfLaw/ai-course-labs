# Track C: AI Systems Administrator labs

- `templates/`: every Track C deliverable template.
- `scripts/`: the Azure CLI commands from C1 to C3 and the C5 usage analysis script.
  Replace every `<placeholder>` before running, and run only in your free sandbox subscription.
- Practice data (permissions, usage, licenses, outages, audit log) is in
  `../industry-packs/<pack>/track-c/`.

The C4 lesson explains configuration as code (Bicep, ARM, Terraform) at awareness level.
The course has no template file to deploy, so none is included here.
