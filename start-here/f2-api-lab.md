# F2 lab: free public test API

Use JSONPlaceholder, a free fake API for practice. No account or key is needed.

1. Open https://jsonplaceholder.typicode.com/users/1 in your browser and read the JSON that comes back.
2. Copy three fields into a spreadsheet: `name`, `email`, `address.city`.
3. Open https://jsonplaceholder.typicode.com/nothing-here and write down the status code you get.

If the site is blocked on a company network, any public test API your team approves works the same way.
